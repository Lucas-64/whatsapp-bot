# Eclipse Arcano — Visão Geral

## Conceito

Eclipse Arcano é um jogo de cartas dark fantasy jogado dentro de grupos de WhatsApp.

Os jogadores assumem o papel de conjuradores, hereges, cavaleiros amaldiçoados, necromantes, caçadores ou criaturas marcadas pelo abismo.

Cada jogador monta um deck com cartas de diferentes tipos e raridades para duelar contra outros jogadores.

## Tom do jogo

O jogo possui uma atmosfera sombria, medieval e arcana.

Palavras-chave:
- dark fantasy
- magia proibida
- ruínas antigas
- pactos demoníacos
- sangue
- relíquias
- maldições
- necromancia
- guerra entre facções
- sacrifício
- corrupção
- redenção impossível

## Objetivo do jogador

Montar um deck poderoso, vencer duelos, conquistar cartas raras, participar de eventos e evoluir sua reputação no grupo.

## Plataforma

O jogo acontece via bot de WhatsApp.

Os jogadores usam comandos simples para:
- abrir grimórios;
- obter cartas;
- montar deck;
- iniciar duelos;
- usar cartas;
- sacrificar cartas;
- interferir em batalhas;
- consultar status;
- participar de eventos.

## Diferencial

Além dos duelos entre dois jogadores, outros membros do grupo podem interferir sacrificando cartas para ajudar ou prejudicar os duelistas.

Isso cria uma dinâmica social, caótica e estratégica.
